# Why Are We Here?

## Core Argument

If AI can already write code for me, I do not need to learn programming simply to compete with it at writing code.

I need to learn programming because generating code is not the same as knowing whether that code actually does what I want. As a designer, I still need enough understanding to describe my intention precisely, read what AI produces, identify problems, and decide whether the result fits my design.

For me, the value of learning programming is therefore shifting from **writing every line myself** to **being able to judge and control what the code does**.

## Working Question

If AI can write the code, what does a designer still need to know?

## Initial Outline

### 1. The question became real for me
- AI can now generate working code very quickly.
- As a designer rather than a programmer, this makes me question why I still need to learn coding myself.
- My answer is not that humans must continue writing everything manually.
- The more important skill may be understanding and judging what the machine produces.

### 2. A concrete example from my VR project
- In my Unity VR project, I designed an interaction where users collect virtual plants and eventually unlock a virtual garden.
- The idea sounds simple when described in one sentence.
- AI could generate a script for a plant collection system very quickly.
- But a working interaction involves many smaller decisions: when collection is triggered, how the count changes, what feedback the user receives, and what happens when the required number of plants is reached.
- The difficult part is not only producing code, but knowing whether the code matches the intended experience.

### 3. Writing code is different from judging code
- AI can provide a plausible script, but plausible does not always mean correct or appropriate.
- Without some programming knowledge, I may not know why something fails or what needs to be changed.
- Understanding basic programming logic gives me the ability to read, test, question, and modify AI-generated code.
- This connects to the difference between simply describing an idea and specifying how a system should actually behave.

### 4. What I think survives
- I may write less code manually in the future.
- But I still need to understand enough programming to maintain control over my design decisions.
- Programming becomes less about memorising syntax and more about understanding logic, behaviour, and consequences.

### 5. Conclusion
- I am not learning programming to become faster than AI at producing code.
- I am learning it so that I can tell the difference between code that merely runs and code that actually serves my design.
