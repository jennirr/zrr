# Process

I used ChatGPT to help me understand the assignment, narrow my topic, organise the structure, and develop the first draft.

One idea I kept was the distinction between **writing code** and **judging code**. I found this useful because it matched my own experience in Unity: AI can generate a script quickly, but I still need to understand whether the logic actually fits the interaction I designed.

One idea I rejected was the broader argument that, because AI lowers the barrier to coding, creativity will simply become more important. I felt this was too general and did not answer the assignment question closely enough. I decided instead to focus on a smaller question: if AI can write the code, why do I still need to understand programming?

I also used AI to help improve the English expression, but I revised the argument based on my own project experience.
